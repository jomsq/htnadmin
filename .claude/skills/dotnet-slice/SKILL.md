# Backend feature slice (.NET 10, EF Core, Postgres)

Read `htn-domain` and `htn-domain/permissions.md` first.

## Folder pattern (per feature area `<Area>`)
```
backend/src/Htn.Domain/<Area>/            Entity.cs, enums, domain methods (state transitions, invariants)
backend/src/Htn.Infrastructure/Data/Configurations/<Area>/EntityConfiguration.cs
backend/src/Htn.Api/Features/<Area>/      <Area>Endpoints.cs, Requests.cs, Responses.cs, Validators.cs
backend/tests/Htn.Api.Tests/<Area>/       <Area>EndpointsTests.cs
```

## Steps
1. **Domain**
   - Entities have private setters and an explicit method per transition (e.g. `Registration.MarkPaid(by, at)`). A method throws `DomainException` when the transition isn't allowed.
   - Money is `decimal`. IDs are `Guid` (v7: `Guid.CreateVersion7()`).
   - Public IDs (participant hash, voucher code, tokens) are generated by `IPublicIdGenerator`, which uses Crockford base32 and `RandomNumberGenerator`.
2. **EF configuration**
   - snake_case tables, `decimal(12,2)`, required lengths, indexes for every lookup/filter used in the design (status, eventId, public IDs unique).
   - Soft-delete or void via a status column. Never use cascade delete on financial or registration data.
3. **Migration**
   - `dotnet ef migrations add <Area>_<Change> -p backend/src/Htn.Infrastructure -s backend/src/Htn.Api`
   - Open the generated file and check: no dropped columns holding data, defaults set for new NOT NULL columns.
4. **Endpoints**
   - A `MapGroup("/api/<area>")` in `<Area>Endpoints.cs`, with `.RequireAuthorization(Policies.X)` on every route.
   - Return `TypedResults`. List endpoints are paged (`?page=&pageSize=`, max 100) with filters matching the design.
5. **Validation:** FluentValidation for each request. Error messages are in plain English for the UI.
6. **Authorization:** add or extend the policy in `Auth/Policies.cs`, plus a resource handler if it's committee-, event- or pop-up-scoped.
7. **Audit:** for sensitive changes, call `IAuditLog.Record(actor, action, entityType, entityId, before, after, reason)` in the same transaction.
8. **Side effects** (emails, auto-posting to the ledger): write an `OutboxMessage` inside the same `SaveChanges`. A background worker sends it, so nothing calls Mailtrap inline.
9. **DTOs:** project with `Select` into response records. Strip board-only fields (prices, TIN, bank) for other roles in the projection.
10. **Tests** (`WebApplicationFactory` + Testcontainers Postgres):
    - the happy path
    - validation 400
    - **403 for a denied role**
    - the audit entry is written
    - the outbox message is queued (when relevant)

## Templates
```csharp
public static class RegistrationEndpoints
{
    public static RouteGroupBuilder MapRegistrations(this IEndpointRouteBuilder app)
    {
        var g = app.MapGroup("/api/events/{eventId:guid}/registrations").WithTags("Registrations");
        g.MapGet("/", List).RequireAuthorization(Policies.RegistrationsManage);
        g.MapPost("/{id:guid}/mark-paid", MarkPaid).RequireAuthorization(Policies.RegistrationsManage);
        return g;
    }

    static async Task<Results<NoContent, NotFound, ValidationProblem>> MarkPaid(
        Guid eventId, Guid id, HtnDbContext db, ICurrentUser me, IAuditLog audit, TimeProvider clock, CancellationToken ct)
    {
        var reg = await db.Registrations.SingleOrDefaultAsync(r => r.Id == id && r.EventId == eventId, ct);
        if (reg is null) return TypedResults.NotFound();
        var before = reg.Status;
        reg.MarkPaid(me.Id, clock.GetUtcNow());                       // domain rule
        audit.Record(me.Id, "registration.mark_paid", nameof(Registration), reg.Id, before, reg.Status);
        db.Outbox.Add(OutboxMessage.Email(EmailTemplate.Ticket, reg.Id)); // ticket + QR sent by worker
        db.Outbox.Add(OutboxMessage.LedgerAutoPost(reg.Id));             // finance auto-post
        await db.SaveChangesAsync(ct);
        return TypedResults.NoContent();
    }
}
```

## Done checklist
- [ ] `dotnet build backend` and `dotnet test backend` pass
- [ ] every route has a policy, and there is a test proving a denied role gets 403
- [ ] migration reviewed; indexes exist for the filters
- [ ] audit and outbox written where the domain requires it
- [ ] no secrets, no sequential public IDs, no float money
